# Isolated execution protocol

Use one worktree or sandbox per active work package. Bind it to the contract baseline and never create it on the protected default branch. Preview the setup command before applying it. Preserve existing worktrees and user changes; a cleanup problem is a stop-and-report event, not a reason to force-delete.

The ledger is the recovery record. It must state what is complete, what evidence is current, what changed after review, the active fix round, unresolved blockers, and the next safe action. Reviewers receive raw diff and evidence in read-only mode; testers use a separately controlled test path and do not repair code.

Choose model tier and reasoning effort from risk and task complexity, record expected budget, and stop when the finite correction limit is reached. Separate role labels do not prove independent principals without host evidence.
