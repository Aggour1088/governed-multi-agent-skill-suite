# Human-Centered Experience Checklist

## Clarity and safety

- Make the purpose, current state, next action, result, and recovery clear.
- Use one primary action per decision point.
- Preserve valid input after recoverable error.
- Use progressive disclosure for advanced choices.
- Use plain language and avoid technical or database labels.
- Confirm destructive actions with consequence-aware language.

## Inclusive use

- Support keyboard navigation, visible focus, labels, contrast, non-colour cues, zoom, target size, semantic structure, and assistive technology.
- Test realistic names, long lists, empty results, errors, latency, mobile, tablet, desktop, supported locales, RTL, dates, numbers, and time zones.
- Record behavior that needs live testing separately from what a static design can prove.

## Ethical human factors

- Reduce memory burden and accidental action.
- Explain consequences before commitment.
- Avoid dark patterns, coercive defaults, hidden costs, deceptive urgency, or misleading progress.
- Preserve informed owner control and user recovery.
