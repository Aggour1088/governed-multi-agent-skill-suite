# Root-Cause Protocol

- Reproduce before diagnosing.
- Prefer measured comparison between working and failing paths.
- Keep one falsifiable hypothesis in flight at a time.
- Change one variable and retain raw evidence.
- Do not mistake a symptom disappearance for a causal explanation.
- Add regression proof that distinguishes the original fault.
- Escalate repeated failed hypotheses or risk of data integrity, security, architectural drift, or broad scope expansion.
