## Important limits

This is a final **source release**, not a host-enforcement product:

- The E1 result does not attest independent agent identity, host-enforced routing, protected deployment, or a host-issued audit trail.
- It does not establish behavior for a different host, model, reasoning configuration, capability profile, or changed router fingerprint.
- The skills guide agents and the validators verify selected source and evidence structures; neither bypasses project access controls nor authorizes a production action.
- Release checksums detect drift but do not authenticate an author. Use a trusted tag/signing path appropriate to your environment.
