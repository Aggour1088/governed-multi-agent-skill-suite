# Workspace Safety Checklist

- Identify the actual repository and every applicable instruction file.
- Preserve uncommitted and unrelated user changes.
- Capture branch/revision, worktrees, generated files, nested repositories, and baseline status.
- Run relevant existing checks before changing the target; distinguish code failure from environment or unavailable tool.
- Confirm contract scope, owned files, permission ceiling, target environment, and no active ownership conflict.
- Require backup, rehearsal, or rollback evidence before data, configuration, migration, or production-impacting work.
- Stop on unclear target, unexplained baseline failure, missing authority, insufficient permission, or potentially destructive overlap.
